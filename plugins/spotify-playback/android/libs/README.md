# Spotify Android App Remote binary

Track Mirror does not commit Spotify's App Remote AAR into this repository.

The Android Tauri plugin expects Spotify's official App Remote 0.8.0 binary at:

`plugins/spotify-playback/android/libs/spotify-app-remote-release-0.8.0.aar`

Use `scripts/fetch-spotify-android-app-remote.sh` from the repository root to download the release asset directly from Spotify's GitHub release.

Upstream release: `v0.8.0-appremote_v2.1.0-auth` in `spotify/android-sdk`.

The binary remains third-party Spotify material and is not part of Track Mirror authorship.
